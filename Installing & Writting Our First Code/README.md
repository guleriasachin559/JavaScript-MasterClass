# 🔍 How to Check Whether Node.js is Installed

## Step-by-Step

1. Press **Start** and search for **Git Bash** or **CMD**
2. Open either application
3. Type the following command and press **Enter:**

```bash
node -v
```

> This will display the currently installed version of Node.js on your machine.

---

## 📦 Check npm (Node Package Manager)

Along with Node.js, it's important to verify that **npm** is also installed. Run:

```bash
npm -v
```

> npm comes bundled with Node.js and is used to install and manage packages/libraries in your project.

---

## ▶️ Command to Run a JavaScript File

Once Node.js is installed, you can execute any `.js` file directly from the terminal:

```bash
node demo.js
```

> Replace `demo.js` with the name of your JavaScript file.
